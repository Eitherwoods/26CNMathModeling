# 问题三求解流程说明

依据 `solutions/modeling-strategy.md` 第 3 章的五项决策，以及
`solutions/REVIEW-Q3-2026-09-11.md` 的审核修正意见实现。

## 1. 问题分析

问题三的难点不在单个几何量，而在四个"不知道"叠加下的**可判定性**：

1. **源数未知**（10–16），所以"清完手上的"不等于"清完了"；
   $N_{\text{source}}\le16$ 只提供"清满 16 即收工"这一个提前终止口径。
2. **示向度只给方向**：读数不含距离，不能把首次收到信号当成目标就在有效接收半径上。
3. **误差按地点固定**：同一停靠点重复检测给出同一读数，重复测量零信息；
   不同地点的误差是同一实现下的空间相关场，**不独立**，
   因此交会必须按"未知但固定的干扰"做鲁棒处理，而不是求平均。
4. **两个时钟**：计分用虚拟时间（移动 + 切换 + 检测 + 光学 + 清除），
   约束用真实程序时间（≤20 min，受 25 min 窗口夹逼，且包含本机计算耗时）。

其中第 1 点决定了策略必须能给出"某频道在目标区域内**不存在**"的严格结论，
这也是本实现把可能位置集合做成栅格掩码、并在其上做严格查询的原因。

## 2. 模型建立

### 2.1 可能位置集合与栅格表示

每个频道 $c$ 维护可能位置集合 $F_c\subseteq\Omega$，
$\Omega=\{G:\|G\|\le1800\}$ 为题目给定的目标圆域（**恒定时求交，保证有界闭**）。
$F_c$ 用规则格网上的布尔掩码表示，格网步长 $h$，
覆盖半径 $r_h=h\sqrt2/2$（格点到区域内任意点的最大距离）。

掩码始终取真实可能集合的 **$r_h$ 外邻域**，由此得到两条严格结论：

| 结论 | 判据 | 用途 |
| --- | --- | --- |
| 该频道在目标区域内确实不存在 | 掩码为空 | 终止条件（第五项决策） |
| 任一可能位置都落在 $p$ 的 $d$ 邻域内 | $\max_q\|q-p\|+r_h\le d$ | 可证清除（第四项决策） |

两类更新都必须朝"不误删"一侧偏离：交类更新按 $+r_h$ 放宽，
差类（排除）更新按 $-r_h$ 收紧。细格网承担全部严格判据，粗格网只用于前瞻评分。

### 2.2 保守更新算子

| 返回结果 | 对 $F_c$ 的更新 | 说明 |
| --- | --- | --- |
| 示向度 $\theta$ | 与 $\theta\pm1^\circ$ 角域求交，并加入 $5<\|G-X\|\le1500$ | 角域与距离区间都按 $r_h$ 外扩 |
| 距离过近 | 与 $B(X,5)$ 求交 | 视为第四项原地可证清除的依据 |
| 无信号 | 排除 $B(X,1000)$ | $1000$ 是有效接收半径的**下界**，对任何源都成立 |
| 清除失败 | 排除 $B(p,20)$ | 清除成功当且仅当距离 $\le20$，失败即"不在 20 m 内" |
| 清除成功 | $F_c\leftarrow\varnothing$，状态置已清除 | 不再进入扫描与清除候选 |

$F_c$ 一般是**非凸集**（有挖空），所以不能沿用问题一"顶点枚举 + 直径"的路线，
只能直接在掩码上做外极值查询。

### 2.3 覆盖式不存在性证明

当已清除数少于 16 时，唯一出路是证明残余频道不存在：需要某些停靠点的
**无信号读数对应的半径 1000 圆域覆盖整个目标圆域**。

采用"中心 + 六边形环"7 点布站，环半径 $r$ 时最坏漏检距离为

$$
L(r)=\max\Bigl\{1800,\ \sqrt{1800^2+r^2-2\cdot1800\cdot r\cos30^\circ}\Bigr\}.
$$

- 可行区间 $r\in[1123,1800]$ m；
- $r=1200$ m：$L=972.8$ m，余量 27 m，环间行进 7200 m（**代码默认取此值**）；
- $r=1558.85$ m（$=1800\cos30^\circ$）：$L$ 最小为 900.0 m，余量 100 m，但行进增至 9353 m；
- 下界：单个停靠点最多覆盖边界圆周的 67.5°，故仅覆盖边界就至少需要 6 个站点。

代价量级：7 个停靠点、10 个待证频道时约 70 次检测（420 s 虚拟时间）
加约 10.9 km 行进（2182 s 虚拟时间），合计约 2600 s 虚拟时间。
虚拟时间上限是 100 h，完全放得下；但行进量已大于 20 min 真实程序时间窗的容量，
**因此覆盖不作为独立阶段单跑，而是折叠进追踪轨迹顺带累积**：
搜索候选停靠点的评分直接用"本次检测可新增排除的面积"，
使覆盖随追击自然增长。

### 2.4 清除判据

- **可证清除**：$\max_q\|q-p\|+r_h\le20$，或最近一次读数已确认目标在 5 m 内；
- **试探清除**：距离上界 $\le45$ m 且**均匀先验**下成功概率 $\ge0.30$，
  $\Pr=\operatorname{area}(F_c\cap B(p,20))/\operatorname{area}(F_c)$。
  该先验是**人为设定**（题目未给分布），必须与敏感性分析一起写入论文。

## 3. 求解方法：五项决策

### 3.1 决策一 + 二：往哪走、走多远（合并为停靠点选择）

方向与步长按**联合决策**处理——候选位移 $(\text{方向}\times\text{长度})$ 上直接打分，
避免"先定方向再定步长"的串行分解丢最优性。

- **追击选项（已知目标）**：目标函数取**最坏剩余距离** $\max_{G\in F_c}\|\cdots\|$
  （极小极大），不取平均。取平均会让机器狗贴着示向线前进（共线退化，
  横向偏差永不闭合）；取最坏值会惩罚长条状残余区域，迫使它横向逼近闭合角域。
  改进措施：残余区域距当前位置不超过 300 m 时改用**近场精细前瞻**
  （细格网 + 中心/八方向/径向候选），远场用粗格网抽样。
- **搜索选项（未发现目标）**：候选停靠点评分

$$
\text{score}=\frac{\text{行进时间}+\text{检测时间}}{\text{期望发现数}}\times1.25+\text{后续清除代价},
\qquad
\text{期望发现数}=\frac{\#\text{未清除源}}{20}\cdot\frac{\text{新增排除面积}}{|\Omega|}.
$$

  先按新增排除面积下限筛选；若全区找不到达标候选（只剩零星残差），
  去掉下限再找一次，避免因残差无法排除而拿不到"不存在"的结论。

### 3.2 决策三：是否扫描某一频率

1. 已清除或已排除的频道不检测；
2. 同一停靠点已取得该频道**任意一类**读数（示向度 / 距离过近 / 无信号）则跳过；
3. 可证清除的频道跳过测向，直接交给第四项；
4. 其余频道按新增排除面积排序，已发现频道全取，未发现频道按增益取前若干个
   （默认每站 3 个，实时预算吃紧时进一步收紧）。

### 3.3 决策四：是否清除某一频率

按"可证清除 → 试探清除（按概率降序）"顺序执行；
同一停靠点对同一频道已清除失败则不再重试。清除指令已合并光学定位与清除，
不另设"是否开启精确定位"的决策。

### 3.4 决策五：是否结束

1. 已清除 16 个不同频道；或
2. 全部 20 个频道的掩码为空（已清除或已证明不存在）。

下列情形**不判完成**：只清了 10 个；某点全频道无信号；某频道掩码突然变空
（此时先查约束一致性与数值误差）。时间不足时以 `exit_margin` 单独标记为受限终止。

### 3.5 预算感知（双时钟）

每执行一次动作后按实测真实耗时估计"还能发多少个动作"
（`_action_capacity`，预留 15 s 用于正常退出），据此动态收紧每站扫描的频道数。
真实时间逼近上限时优先保证退出流程，而不是继续搜索。

## 4. 运行方法

在项目根目录执行（不能先进入 `codes`）：

```powershell
python -m unittest codes.test_problem3 -v
python -m codes.problem3_solution --seed 7 --sources 12
python -m codes.problem3_solution --seed 7 --sources 12 --figures
python -m codes.problem3_solution --sources 12 --latency 0.05
```

窗口期用运行器加载正式入口（人工启动模拟器后执行）：

```powershell
python -m codes.run_robot --strategy codes.strategy_p3:solve --problem 3
```

**测试纪律**：`tester/README.md` 明确要求 AI 不得自行正式测试。
本项目的自动化测试与上述命令行只使用本地桩 `OfflineStub`，
演练测试与正式测试一律由人工在模拟器界面触发。
