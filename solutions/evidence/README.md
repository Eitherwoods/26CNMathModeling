> 三条相互独立的支持线：①速通前沿实测（砍光证书也只 232 s/源 @ 81.5% 清除率）；
> ②BHH 松弛物理下界（启发式，~190–205）；③架构地板分解（覆盖巡回 + 追击 +
> 排除测量三项均被数学/物理锁死）。详见各分文件。

## 论文撰写快速指引

1. **结果表**：用"核心数字速查"行 1–2；演练单局作佐证并注明案例构成。
2. **权衡分析**：引用 `figures/Problem3/sprint_tradeoff.png`（论文版 SVG 同名），
   说明清除率与平均清除时间不可兼得，180 位于前沿左外侧。
3. **下界讨论**：引用 p3/p4 证据文件的"下界核算"节；BHH 常数必须标注为启发式。
4. **消融表**：直接取 p3/p4 证据文件的"证伪/消融全表"，每行都有数据来源。
5. **禁止的表述**：见各分文件"使用限制"；特别注意 532.1 与 678.0 两局案例构成
   不同（定向占比 29% vs 64%），不可配对比较。

## 一切数字的可复现性

本地数字全部产生于 `codes/benchmark_q34_local`（官方演练模式的进程内复刻，
线程数固定为 1，任意两次运行逐位相同）。复现命令、数据 JSON 路径在
[measurement-methodology.md](measurement-methodology.md) 与各分文件中逐条给出。
官方演练记录在 `output/Problem3|4/mission_*.json`（配对 TXT 在
`output/protocol/`），由模拟器侧行为日志独立佐证。
