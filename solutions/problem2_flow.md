# 问题二求解流程说明

## 1. 问题分析

第一次示向度把干扰源限制在目标圆域、有效接收距离和角度误差共同形成的扇形环域中。第二检测点既要对所有可能位置保持可接收，也要避免两次示向方向近乎平行。

## 2. 模型建立

代码以该可能区域的内部点和边界点离散表示。可靠候选点必须满足全部边界样本的距离不超过 `1000 m - h`，其中 `h` 是由极坐标与边界采样步长导出的覆盖裕量。因此，数值求解不会把有限采样直接当作连续区域。

对每个可靠点，枚举可能真实位置和第二次误差 `-1, 0, 1` 度；对每次可能读数计算剩余采样定位集的直径，并以其中最大值作为稳健质量指标。五米以内的情形使用距离过近圆域，示向度分支显式排除五米以内位置。

## 3. 求解方法

运行：

```powershell
python -m codes.problem2_solution --station 0 0 --bearing 0
```

可用 `--candidate-step` 调整第二检测点网格。较小步长使候选区域更细；同时应相应减小首次区域与边界采样步长，并重跑结果。

## 4. 文件清单

- `codes/problem2_solution.py`：求解器、JSON 输出与命令行入口。
- `codes/test_problem2.py`：跨零角度、近距离、可靠裕量和端到端测试。
- `figures/Problem2/problem2_candidates.png`、`.svg`：候选区域图。
- `output/Problem2/problem2_results.json`：数值结果。
