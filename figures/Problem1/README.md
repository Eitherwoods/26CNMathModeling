# 问题一验证图 README

本目录包含问题一算法验证的两组图，均由附录代码生成，用于展示定位区域构造、直径计算及直径圆覆盖性结论。由于部分 AI 无法直接查看图像，本 README 描述图像内容、坐标、图例和用途。

## 图1：正三角形反例（D = 10.000000 m）

**对应文件**：`triangle.png`

### (a) 人工验证场景与示向边界
- **坐标系**：x 轴约 -300 至 200，y 轴约 -300 至 300，单位米。
- **检测点**：
  - S1 = (-300, 0)
  - S2 = (160, -150√3) ≈ (160, -259.8)
  - S3 = (155, 155√3) ≈ (155, 268.5)
- **示向边界**：每个检测点发出一个张角为 2° 的示向角域，用两条虚线表示边界。三个示向角域的交集构成正三角形定位区域。
- **真实位置**：黑色星号表示设定的真实干扰源位置，位于正三角形重心附近。
- **用途**：展示正三角形定位区域可由题目允许的示向约束形成，检测点到三角形距离约 300 m，小于最小有效接收半径 1000 m。

### (b) 局部定位区域：D = 10.000000 m
- **坐标系**：x 轴约 -5 至 12.5，y 轴约 -2 至 10，单位米，局部放大。
- **定位区域**：蓝色填充区域为正三角形。
- **最远顶点对**：紫色线段为算法找到的最远顶点对，其长度即定位区域直径 **D = 10.000000 m**。
- **真实位置**：黑色星号为设定真实位置。
- **直径圆**：红色圆为以最远顶点对为直径端点的圆，半径 D/2 = 5 m。
- **关键现象**：正三角形第三个顶点位于红色圆外，超出距离约 **3.660254 m**。这直观说明“以定位区域直径为直径的圆不能覆盖整个定位区域”。
- **用途**：验证问题一“直径圆非普遍覆盖”的结论。

## 图2：五检测点实例（D = 22.775384 m）

**对应文件**：`five_stations.png`

### (a) 人工验证场景与示向边界
- **坐标系**：x 轴约 -400 至 1000，y 轴约 -300 至 1000，单位米。
- **检测点**：
  - S1 = (-400, 0)
  - S2 = (0, -300)
  - S3 = (1000, 0)
  - S4 = (900, 1000)
  - S5 = (-300, 1000)
- **示向边界**：每个检测点对应一个 2° 示向角域，用虚线边界表示。五组示向角域交会形成定位区域。
- **真实位置**：黑色星号表示设定的真实干扰源位置 **G = (300, 400)**。
- **用途**：展示一般多检测点交会定位场景，所有检测点到真实源距离均小于 1000 m。

### (b) 局部定位区域：D = 22.775384 m
- **坐标系**：x 轴约 290 至 315，y 轴约 385 至 410，单位米，局部放大。
- **定位区域**：蓝色填充区域为算法计算出的凸五边形。
- **最远顶点对**：紫色线段为最远顶点对，其长度即定位区域直径 **D = 22.775384 m**。
- **真实位置**：黑色星号为设定真实位置 (300, 400)，位于定位区域内。
- **用途**：验证顶点提取、半平面约束筛选和顶点对直径算法的正确性，展示问题一算法在一般多检测点情形下的输出。
