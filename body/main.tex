\title{基于测向机示向度的无线电干扰源自动定位与清除策略}

\begin{document}

\maketitle

\begin{abstract}
    针对问题一，将示向度误差刻画为以检测点为顶点的 $2\varepsilon$ 示向角域，其交集构成\textbf{有界凸多边形定位区域 $P$}；提出\textbf{顶点枚举算法}并以命题证明其对定位区域顶点的完备性，由直径必在顶点对处取得将计算化为顶点对距离最大化，总复杂度 $O(m^3+n^2)$；五站数值实例（直径 $22.775384$ 米、残差 $10^{-14}$ 米量级）验证了模型精度；进而构造满足题目全部约束的正三角形定位区域，严格证明\textbf{直径圆不具普遍覆盖性}，再以\textbf{最小覆盖圆}建立 $r(P)\le20$ 与\textbf{可靠清除点存在性等价}的判据，为后续清除策略奠定几何基础。

    针对问题二，将固定但未知的接收半径纳入\textbf{“位置—半径”联合可行集}并投影得可能位置区域 $F_1$；以保障性接收圆的交集定义\textbf{可靠接收区域 $C_{\mathrm{rec}}$}，经自适应网格证书连续认证；提出\textbf{纯几何鲁棒价值模型}，以最小覆盖圆尺度与面积定义\textbf{几何不确定性 $\Phi$}，以最坏相容反馈下 $\Phi$ 的\textbf{保证减少量 $\Delta$}评价候选点，不依赖概率分布假设；按 $\Delta\ge(1-\rho)\,\Delta_{\max}$ 经认证上下界两级筛选得\textbf{优良候选区域 $C_{\mathrm{good}}$}，最终选取 $\Delta$ 最大的经验证代表点为 $S_2^*$，同分按坐标词典序，\textbf{输出唯一确定}。

    针对问题三，设计\textbf{“扫描—追击”两相滚动策略}：以原点与半径 $1200$ 米正六边形共七个扫描锚点批量测量发现目标，目标圆域的 $40$ 米剖分单元被无信号扫描整单元覆盖即\textbf{严格划除}，全部耗尽构成空频道的\textbf{不存在性证书}；发现即以可能位置区域的\textbf{最小覆盖圆}为标尺追击——半径不超过 $20$ 米\textbf{证书清除}、较小时\textbf{试探清除}，否则按“行进$+$前进$+$不确定”统一尺度选保证收信的测量点；扫描位置作\textbf{证书保持迁移}，已发现频道与剩余锚点合成最近邻$+$2-opt \textbf{联合开放路线}，清满 $16$ 个由总数上界\textbf{短路收工}。本地同构复现 $24$ 种子 $275.4$ 秒/源、官方演练 $26$ 局 $269.9$ 秒/源，全部清除。

    针对问题四，将存在假设扩展为\textbf{位置—半径—类型—朝向联合假设}，以“$20$ 米$\times4$ 半径$\times24$ 朝向”布尔张量保守维护定向无信号的析取分支，并用\textbf{方向位图}把凸包发现证书实现为可增量更新的严格判据；发现保证由中心$+$三重同心环共 $30$ 个扫描顶点实现，外环 $12$ 点是边界任意朝向覆盖的几何下界；清除只依赖 $20$ 米位置覆盖证书，失联仍可推进；成熟频道的清除候选与剩余扫描顶点合并进\textbf{同一条最近邻$+$2-opt 滚动开放路线}，辅以交错调度与自适应追踪。本地 $12$ 种子 $549.6$ 秒/源、官方演练 $10$ 局 $541.9\sim587.6$ 秒/源，全部完整收尾。

\keywords{交会定位；定位区域直径；最小覆盖圆；可靠接收区域；鲁棒价值模型}

% ==================== 问题重述 ====================
\section{问题重述}

\subsection{问题背景}

无线电干扰源的定位与清除是无线电频谱管理中的核心任务。传统流程分为初步监测、区域性排查和精准定位三个阶段：前两个阶段借助固定监测站、移动监测车或无人机完成大范围信号采集与区域圈定；而受环境遮挡、低功率干扰源等因素制约，每个干扰源的最终\textbf{精准定位}仍需技术人员携带便携式测向机徒步排查\upcite{ge2021}，通过分析信号场强与方向特征逐步锁定位置并清除，耗时长、人力成本高，且在危险环境中存在安全隐患。

为提升定位与清除效率，某公司拟研发搭载于机器狗的干扰源自动定位清除系统：利用测向机检测干扰源场强变化以推断方位信息（示向度），并结合光学探测仪实现精确定位与激光清除。

目标分布区域为半径$1800$米的圆形区域，以圆心为原点、正东为$x$轴正向、正北为$y$轴正向（单位：米），区域内干扰源个数未知。干扰源特征：每个干扰源占据互不相同的频道（编号$1$至$20$），信号互不影响；按覆盖角度分为全向（有效覆盖$360^\circ$）与定向（定向方向两侧各$90^\circ$）两类，有效覆盖范围内信号均匀辐射，场强仅随距离衰减。测向机有效接收半径为$1000\sim1500$米，示向度误差在$[-1^\circ,1^\circ]$内。机器狗直线行进速度$5$米/秒，移动中无法检测，频道切换每次$1$秒、获取稳定示向度每次$5$秒；\textbf{距干扰源不超过$20$米时可光学精确定位（$3$秒）并以激光清除（$2$秒）}，不超过$5$米且位于有效覆盖范围内时因信号过强无法获得示向度，可直接光学定位与清除。

\subsection{问题提出}

根据上述背景及附件所给参数，本文需要建立数学模型解决以下四个问题：

\textbf{问题一}：已知若干检测点坐标及某干扰源关于这些点的示向度，给出交会定位的多边形\textbf{定位区域直径}（区域内任意两点距离的最大值）计算算法，并判断以该直径为直径的圆\textbf{能否覆盖定位区域}。

\textbf{问题二}：已知某全向干扰源在一个检测点处的示向度，给出第二个检测点的\textbf{选择策略与候选区域}，以获得较好的定位效果。

\textbf{问题三}：目标区域内均为全向源，总数$10\sim16$个但个数未知。机器狗从原点出发（初始频道$1$）自动定位并清除全部干扰源，要求在确保清除的前提下\textbf{总时间越短越好}；需制定搜索定位与清除策略并设计算法，经模拟器演练计算清除比例与平均定位清除时间等统计量，并进行三次正式测试。

\textbf{问题四}：目标区域内同时存在全向与定向源，总数仍为$10\sim16$个，\textbf{定向源个数与方向未知}，其余条件同问题三；给出检测与清除策略及算法，演练检验有效性并进行三次正式测试。

% ==================== 问题分析 ====================
\section{问题分析}

与本文相关的已有研究可分为四支：有界测向误差下的多站交叉定位区域估计\upcite{xu2011}刻画了示向角域相交形成定位多边形的几何结构；无线电干扰源移动排查策略与精准定位算法\upcite{ge2021}提供了移动测向排查的工程背景与流程参照；平面点集最小覆盖圆的快速求解及其几何性质\upcite{zhu2015}为定位区域的覆盖性判定提供了计算工具；谨慎贪心主动选点与有界不确定性下的传感器布置和选择\upcite{vanderhook2012,tokekar2013,vanderhook2014}体现了“定位收益—移动代价”联合评价的主动定位思想。本文保留上述思想，并结合本题未知频道数、有限接收半径与清除判据的要求，补充建立全域覆盖证书等本题特有的机制。

\subsection{问题一分析}

问题一需要设计交会定位的定位区域直径算法，判断直径圆能否覆盖定位区域，并给出能覆盖整个定位区域的圆。示向度误差使真实方位落在宽度$2^\circ$的角区间内，由此得到以检测点为顶点、可表示为两个半平面交集的\textbf{示向角域}；所有角域的交集即定位区域$P$，非空有界时为\textbf{凸多边形}，顶点由不平行边界直线交点筛选得到，\textbf{直径归结为顶点对距离最大化}。直径圆覆盖性以\textbf{正三角形反例}说明不具普遍覆盖性；再以\textbf{最小覆盖圆}给出能覆盖整个区域的圆，其半径是否不超过$20$米对应\textbf{可靠清除点}是否存在。

\subsection{问题二分析}

问题二针对已知单点示向度求第二检测点选择策略与候选区域。首次检测确定包含未知接收半径的\textbf{联合可行集}与位置投影区域$F_1$；为保证第二次检测能可靠接收信号，取所有可能位置的保障性接收圆交集构成可靠检测区域$C_{\mathrm{rec}}$；进而在可靠区域内建立纯几何检测价值模型：以最小覆盖圆半径与面积构造\textbf{几何不确定性$\Phi$}，以最坏相容反馈下$\Phi$的保证减少量$\Delta$评价候选点，筛出价值接近最优的\textbf{优良候选区域$C_{\mathrm{good}}$}，并在经验证代表点中取基础价值最大者（同分坐标词典序）为最佳第二检测点；行进距离与检测耗时不计入本问评分，留待问题三引入。

\subsection{问题三分析}

问题三要求在干扰源总数未知（$10\sim16$个）时自动搜索、定位并清除全部全向源，且总虚拟时间越短越好。本文采用\textbf{“扫描—追击”两相滚动策略}：以原点与半径 $1200$ 米六边形共七个扫描锚点为发现与排除基线，把目标圆域剖分为 $40$ 米方格单元并按“整单元落在某锚点 $999.99$ 米接收圆内”分配，任何单元被无信号扫描覆盖即可从该频道可能位置中严格划除；每站对全部未决频道批量测量，发现即以可能位置区域的最小覆盖圆为标尺追击——半径不超过 $20$ 米就地可靠清除、较小时按实测置信试探清除，否则沿“当前位置—圆心”走廊选择行进与不确定代价最小的保证收信测量点；扫描位置沿锚点方向作证书保持迁移，已发现频道与剩余扫描锚点合成最近邻$+$2-opt 开放路，每次反馈后重新排序；清满 $16$ 个由总数上界短路收工，其余空频道最终由覆盖证书统一严格排除，任务在有限步内完成。

\subsection{问题四分析}

问题四在问题三框架上引入定向源，新增困难是无信号解释不唯一、发现保证失效与类型朝向耦合。将存在假设扩展为位置、半径、类型与发射方向的\textbf{联合假设}，定向无信号解释为“距离过远或位于发射背面”并保留析取分支；解析消去接收半径，把朝向缩小纳入联合几何量$\Phi_4$的价值评价；发现保证改用“距源不超过$1000$米的已测点凸包”证书，以“$20$米位置单元$\times24$朝向区间”的方向位图实现为可增量更新的严格判据，并由中心$+$三重同心环共$30$个扫描顶点实现布站（外环$12$点为边界任意朝向覆盖的几何下界）；清除仅依赖$20$米位置覆盖证书，不要求先恢复信号或识别朝向；搜索顶点、追踪目标与成熟频道的后备清除候选合并进同一条最近邻$+$2-opt 滚动开放路线，每轮反馈后重排。

% ==================== 模型假设 ====================
\section{模型假设与合理性说明}

\begin{description}
\item[1. 误差与平面假设] 示向度误差在$[-1^\circ,1^\circ]$内，同一地点电磁环境固定，重复检测\textbf{不提高精度}；测向机与干扰源位于同一平面，在有效覆盖角度范围内信号场强仅随距离衰减。
\item[2. 参数固定与信号独立] 不同干扰源信号互不影响；同一干扰源的位置、频道、有效接收半径（及类型、朝向）在一次任务中\textbf{保持固定}。
\item[3. 坐标系与区域] 以目标区域圆心为原点、正东为$x$轴正向、正北为$y$轴正向（米）；目标圆域$\Omega=\{G\in\mathbb R^2:\|G\|\leq1800\}$，检测点与清除点可位于域外。
\item[4. 距离过近的闭包处理] 第一次获得示向度后，可能位置区域用$5\le\|G-S_1\|$的闭包作保守计算；处理新的 direction 反馈时，按物理规则排除对应的$5$米闭圆$B(X,5)$。
\item[5. 测量接口反馈] 接口只返回 direction、near 或 no\_signal，direction 附带示向度而不返回场强；每次只检测一个频道，清除不切换频道，退出不要求返回原点，清除失败也是有效观测。
\item[6. 滚动重规划] 每轮先按当前信息确定候选目标集，对其求一条高质量开放访问路线（最近邻$+$2-opt 局部改进）并只执行首站，获得反馈后重新选点与排序；路线排序是当前固定点集上的启发式可行解，选点具有短期性，\textbf{两种最优性不混用}。
\end{description}

% ==================== 模型准备 ====================
目标区域为半径 $1800$ 米的圆域 $\Omega=\{G\in\mathbb R^2:\|G\|\le1800\}$，干扰源位置记为 $G$，检测点记为 $S$，示向误差上界 $\varepsilon=1^\circ$。角度环形距离 $d_\theta(\alpha,\beta)=\left|((\alpha-\beta+180^\circ)\bmod 360^\circ)-180^\circ\right|$，\textbf{示向角域} $W(S,\theta)=\{p:d_\theta(\arg(p-S),\theta)\le\varepsilon\}$（可表示为两个半平面的交集）。对任意位置集合 $F$，定义直径、最大距离、\textbf{最小覆盖圆半径}与\textbf{可靠清除点集}：
\[
D(F)=\sup_{Y,Z\in F}\|Y-Z\|,\quad
R_F(X)=\sup_{G\in F}\|G-X\|,\quad
r(F)=\inf_X R_F(X),
\]
\[
K_{20}(F)=\{X:R_F(X)\le20\}=\bigcap_{G\in F}B(G,20),
\qquad
K_{20}(F)\ne\varnothing \iff r(F)\le20.
\]
任务总虚拟时间为
\[
T=\frac{L}{5}+N_{\mathrm{switch}}+5N_{\mathrm{measure}}
+3N_{\mathrm{clear,fail}}+5N_{\mathrm{clear,success}},
\]
其中 $L$ 为总直线移动距离。数学叙述中的角度默认以度为单位，代入三角函数时先转为弧度。本文问题三、四以\textbf{“扫描—追击”动态滚动策略}为主线：问题一建立定位区域与最小覆盖圆算法，问题二建立纯几何的检测价值模型，问题三引入批量扫描、行进代价与滚动开放路线，问题四将上述框架扩展至定向源。后续各问题直接引用以上定义，不再重复。

\section{问题一：定位区域直径算法、直径圆覆盖性判定与覆盖圆求解}\label{sec:q1}

\subsection{基于定位区域顶点的直径算法}

\textbf{（1）示向角域与定位区域。}设共有 $m$ 个检测点，第 $i$ 个检测点为 $S_i=(x_i,y_i)$，在该点测得的干扰源示向度为 $\theta_i$。由于示向度误差位于 $[-1^\circ,1^\circ]$ 内，真实方位位于 $[\theta_i-\varepsilon,\;\theta_i+\varepsilon]$（$\varepsilon=1^\circ$）。记 $\alpha_i=\theta_i-\varepsilon$，$\beta_i=\theta_i+\varepsilon$，则以 $S_i$ 为顶点、以上述角度范围为边界的\textbf{示向角域}可表示为两个半平面的交集：
\begin{equation}\label{eq:halfplane}
W_i=W(S_i,\theta_i)
=\{p:a_{i,\pm}^{\mathsf T}p\leq b_{i,\pm}\},
\end{equation}
其中 $a_{i,-}=(\sin\alpha_i,\,-\cos\alpha_i)$，$a_{i,+}=(-\sin\beta_i,\,\cos\beta_i)$，$b_{i,\pm}=a_{i,\pm}^{\mathsf T}S_i$。这两个约束同时保留以 $S_i$ 为顶点、朝向 $\theta_i$ 的前向角域，不会误取其反向延长区域。同一干扰源必须满足所有检测点的示向约束\upcite{xu2011}，故\textbf{定位区域}为
\begin{equation}\label{eq:loc_region}
P=\bigcap_{i=1}^{m}W_i=\{p:Ap\leq b\}.
\end{equation}

先看 $P$ 的凸性。任意半平面都是凸集，每个 $W_i$ 自然也是凸集；再任取 $P$ 中两点，其连线段同属每一个 $W_i$，从而属于 $P$，可见 $P$ 为凸集。至于有界性：$P$ 的边界来自有限条示向边界直线，只要交会条件形成非空有界区域，$P$ 就是\textbf{有界凸多边形}，特殊情形下退化为点或线段——这一结构正是后续按极角排列顶点、使用旋转卡壳法的依据。

\textbf{（2）顶点提取。}记矩阵 $A\in\mathbb R^{2m\times2}$ 的第 $k$ 行为 $A_k=(A_{k1},A_{k2})$，向量 $b$ 的第 $k$ 个分量为 $b_k$，则式~\eqref{eq:loc_region} 中第 $k$ 条候选边界直线为 $A_{k1}x+A_{k2}y=b_k$。定位区域的顶点必由其中两条非平行边界直线相交得到（完备性由下述命题保证），故可采用\textbf{枚举求交、再逐点筛选}的方法提取全部顶点。任取两条边界直线 $k<\ell$，定义其系数行列式
\begin{equation}\label{eq:det_kl}
\Delta_{k\ell}
=A_{k1}A_{\ell2}-A_{k2}A_{\ell1}.
\end{equation}
当 $|\Delta_{k\ell}|>\tau_{\parallel}$ 时，两条直线不平行，由克拉默法则得到唯一交点
\begin{equation}\label{eq:cramer_kl}
p_{k\ell}
=\begin{pmatrix}x_{k\ell}\\ y_{k\ell}\end{pmatrix}
=\frac{1}{\Delta_{k\ell}}
\begin{pmatrix}b_kA_{\ell2}-A_{k2}b_\ell\\ A_{k1}b_\ell-b_kA_{\ell1}\end{pmatrix}.
\end{equation}
所有不平行边界对给出初选交点集
$\mathcal V_0
=\left\{p_{k\ell}:1\leq k<\ell\leq2m,\;
|\Delta_{k\ell}|>\tau_{\parallel}\right\}$；
交点只有满足全部半平面约束才属于定位区域，故最终顶点候选集为
\begin{equation}\label{eq:V_filter}
\mathcal V
=
\left\{p\in\mathcal V_0:
A_rp\leq b_r+\tau_f,\quad r=1,\ldots,2m
\right\},
\end{equation}
其中 $\tau_{\parallel}$、$\tau_f$ 分别为近似平行判定与半平面可行性容差。对 $\mathcal V$ 中距离不超过去重容差 $\tau_v$ 的点合并，便得到互异顶点 $V_1,\ldots,V_n$。

\begin{proposition}[顶点枚举的完备性]\label{prop:vertex-complete}
设 $P$ 为正常的二维定位区域，则每个顶点必由至少两条不平行的有效边界线相交得到；反之，任一满足全部约束的不平行边界交点都是 $P$ 的顶点。因此 $\mathcal V$ 恰为 $P$ 的全部顶点。
\end{proposition}
\begin{proof}
若某顶点 $V$ 处不存在两条法向量线性无关的有效约束，则所有在 $V$ 处取等号的约束法向量至多张成一维空间，存在非零方向 $d$ 与之都正交；其余约束在 $V$ 处严格成立，故可取充分小的 $t>0$ 使 $V\pm td$ 仍可行，此时 $V=\frac12(V+td)+\frac12(V-td)$，与 $V$ 是极点矛盾。反之，满足全部约束的不平行边界交点由两个独立等式唯一确定，必为顶点。
\end{proof}

为了得到沿边界排列的顶点序列，计算顶点算术平均 $\bar V=\frac1n\sum_{j=1}^{n}V_j$，再按极角 $\phi_j=\operatorname{atan2}(y_j-\bar y,\;x_j-\bar x)$ 从小到大排序；由 $P$ 的凸性，该顺序就是多边形的边界顺序，可直接供后续直径算法使用。

整个求解流程如\cref{fig:flow-diameter} 所示：先作线性可行性判断以排除空区域，再独立检查有界性，随后枚举筛点并排序，最后按顶点仿射维数分类计算直径。

容差方面，$\tau_{\parallel}$ 取无量纲的角度容差，$\tau_f$ 与 $\tau_v$ 则按问题尺度取距离容差。需要强调的是，不能仅因有限枚举未找到交点就断言区域为空——可行性与有界性必须先行独立判断。

顶点提取需枚举 $O(m^2)$ 对边界、每个交点检查 $O(m)$ 个约束，复杂度为 $O(m^3)$。

\textbf{（3）直径的顶点可达性。}本题的定位区域 $P$ 虽是有界凸多边形，但下面的论证更具一般性：对任意有界闭合多边形（无论凸凹），区域内相距最远的两点总可取为其顶点。设最远点对为 $A,B$，$D=\|A-B\|$。先看 $A,B$ 会不会落在内部：倘若 $A$ 是内部点，沿由 $B$ 指向 $A$ 的方向再前进一小段，得到的点 $A'$ 仍在区域内，却有 $\|A'-B\|>\|A-B\|$，与最远性矛盾，因此 $A,B$ 都在边界上。再看边界情形：若 $A$ 位于某条边 $UV$ 内部，则存在 $0<t<1$ 使 $A=(1-t)U+tV$，由三角不等式，
\begin{align*}
\|A-B\|
& =\left\|(1-t)(U-B)+t(V-B)\right\| \\
&\leq (1-t)\|U-B\|+t\|V-B\|\\
&\leq \max\{\|U-B\|,\;\|V-B\|\}.
\end{align*}
由此可见，$U,V$ 中至少有一个到 $B$ 的距离不小于 $\|A-B\|$；而 $\|A-B\|$ 本就是区域内最大距离，故该端点到 $B$ 的距离恰为 $D$。换句话说，把 $A$ 换成顶点并不改变区域直径。对 $B$ 重复同样的论证，即得多边形区域的\textbf{直径必可由一对顶点取得}：
\[
D(P)=\max_{1\le i<j\le n}\|V_i-V_j\|.
\]

\textbf{（4）直径计算与复杂度。}设 $V_i=(x_i,y_i)$，$i=1,\ldots,n$，则定位区域的直径为
\begin{equation}\label{eq:diameter}
\boxed{
D(P)=\max_{1\leq i<j\leq n}
\sqrt{(x_i-x_j)^2+(y_i-y_j)^2}
}\,.
\end{equation}

具体计算时只需双重循环遍历全部顶点对，复杂度 $O(n^2)$。定位区域的顶点数通常不多，这样遍历已经足够；若检测点规模很大，还可借助凸多边形上的\textbf{旋转卡壳法}把这一步降到 $O(n)$——当然，这只是计算层面的加速，不改变模型本身。连同顶点提取在内，正常二维定位区域的总计算复杂度为
\begin{equation}\label{eq:complexity}
O(m^3+n^2).
\end{equation}

此外还有一条实用的性质：若逐次加入新的检测点并保留全部旧观测，则 $P_{m+1}=P_m\cap W_{m+1}\subseteq P_m$，于是 $D(P_{m+1})\leq D(P_m)$，\textbf{观测越多、区域反而越小}。不过这一单调性只在增量检测下成立；若重新布置全部测站，所得区域之间并无包含关系。

\subsection{直径圆不具有普遍覆盖性}

先要指出，“以定位区域直径为直径的圆”这一说法本身就不唯一——还得指明直径端点是哪两个点。更关键的是，即便取一对最远顶点作为端点，这样的圆也未必能覆盖整个定位区域。为此我们构造一个\textbf{严格反例}，第一步先说明正三角形确实可以由题目允许的示向约束形成。

考虑边长为 $10$ 米的正三角形 $A=(0,0)$，$B=(10,0)$，$C=(5,\;5\sqrt{3})$，重心 $O=(5,\frac{5\sqrt{3}}{3})$。取检测点及示向度 $S_1=(-300,0)$，$\theta_1=1^\circ$，其角域 $[0^\circ,2^\circ]$ 包含整个三角形且一条边界与 $AB$ 重合（从 $S_1$ 指向 $C$ 的方向 $\arctan\frac{5\sqrt3}{305}\approx1.626^\circ$）。

再将 $S_1$ 及其角域绕 $O$ 旋转 $120^\circ$、$240^\circ$，得 $S_2=(160,-150\sqrt{3})$，$\theta_2=121^\circ$ 与 $S_3=(155,155\sqrt{3})$，$\theta_3=241^\circ$，相应角域各含三角形且边界分别与 $BC$、$CA$ 重合，故 $\triangle ABC\subseteq W_1\cap W_2\cap W_3$；另一方面，记 $H_{AB},H_{BC},H_{CA}$ 为以三边为界、含三角形内部的半平面，各角域分别包含于其中，而 $H_{AB}\cap H_{BC}\cap H_{CA}=\triangle ABC$，故 $W_1\cap W_2\cap W_3\subseteq\triangle ABC$。两层包含关系给出
\begin{equation}\label{eq:triangle_region}
W_1\cap W_2\cap W_3=\triangle ABC.
\end{equation}
三个检测点到三角形的距离均约 $300$ 米，小于最小有效接收半径 $1000$ 米，检测点与三角形又都落在目标圆域之内，因此这一构造满足题目的全部约束——\textbf{正三角形确实可以成为本题的定位区域}。

设正三角形边长为 $d$，则区域直径 $D=d$，以直径作圆的半径只有 $d/2$。圆要盖住正三角形，至少得盖住它的三个顶点；而三个顶点的最小覆盖圆正是外接圆，半径 $d/\sqrt{3}>d/2$。相比之下，直径圆的半径不够用，自然罩不住整个三角形。于是得到结论：
\begin{equation}\label{eq:coverage_conclusion}
\boxed{\text{直径圆不能保证覆盖多边形定位区域。}}
\end{equation}

从数值上看，程序得到的三个定位区域顶点与理论顶点 $A$、$B$、$C$ 的坐标误差不超过 $3\times10^{-13}$ 米，最大半平面约束残差约 $1.78\times10^{-15}$ 米，算得直径为 $10.000000$ 米；取最远顶点对作直径圆时，第三个顶点落在圆外，超出约 $3.660254$ 米，恰与理论值 $\frac{\sqrt{3}}{2}d-\frac{d}{2}$ 相符。数值与理论在此完全对上，印证了“以定位区域直径为直径的圆”不具有普遍覆盖性。

\subsection{能覆盖定位区域的最小覆盖圆：问题三的几何基础}

后续清除干扰源时，真正需要的是能包住整个定位区域的圆。然而一般多边形未必存在经过全部顶点的外接圆，这里便改用\textbf{最小覆盖圆}\upcite{zhu2015} $r(P)=\min_{C}\max_{1\le j\le n}\|V_j-C\|$，最优圆心记为 $C^\ast$。好在这一替换并无损失：圆是凸集，盖住全部顶点就等于盖住其凸包，故这个有限点问题与覆盖整个多边形是一回事。

再进一步看，最优圆由至多三个活动边界点确定——圆心必须落在活动边界点的凸包内，否则朝凸包方向移动就能同时缩短到各活动边界的距离，与最优性矛盾；落到二维情形，便对应单点、两点直径与三点外接圆这三类情形。顶点对的圆心与半径为 $C_{ij}=\frac{V_i+V_j}{2}$，$r_{ij}=\frac{\|V_i-V_j\|}{2}$；顶点三元组的外接圆圆心 $C$ 由线性方程组
\begin{equation}\label{eq:circle_ijk}
2(V_j-V_i)^{\mathsf T}C=\|V_j\|^2-\|V_i\|^2,\qquad
2(V_k-V_i)^{\mathsf T}C=\|V_k\|^2-\|V_i\|^2
\end{equation}
求得，三点共线时直接跳过。随后枚举单点圆、顶点对直径圆与顶点三元组外接圆，保留能覆盖全部顶点的最小者：候选圆至多 $O(n^3)$ 个，朴素枚举耗时 $O(n^4)$，规模较大时不妨改用增量式最小圆实现。算法还会记下最终圆的支撑点（即决定该圆的那几个边界顶点），供问题三动态更新覆盖圆时复用。

由最小覆盖圆判据，$K_{20}(P)=\bigcap_{j=1}^{n}B(V_j,20)$，且
\begin{equation}\label{eq:K20_crit}
K_{20}(P)\neq\varnothing
\iff
r(P)\leq20,
\end{equation}
条件一旦成立，圆心 $C^\ast\in K_{20}(P)$ 本身就是一个\textbf{可靠清除点}，整个 $K_{20}(P)$ 都是可供选择的清除行动点区域。

需要提醒的是，直径不超过 $40$ 米仅仅是 $r(P)\leq20$ 的\textbf{必要条件}，切不可拿“定位直径与 $20$ 米比大小”来充当清除判据；譬如问题三就会对可能位置区域构造保守多边形外包、以支撑点增量更新覆盖圆，并给出认证覆盖半径上界。

\section{问题二：基于几何检测价值的第二检测点选择}

在单点交会定位中，仅凭一次检测往往难以精确锁定干扰源位置。本节假定已知第一检测点 $S_1$ 及其示向度 $\theta_1$（目标为全向源），依次考察候选检测点与已有观测所确定区域之间的关系——能不能收到信号、不同反馈会把区域压缩到什么程度、候选点的几何价值有多大——在此基础上给出\textbf{第二检测点的候选区域}。至于行进距离与检测耗时，本问暂不计入评分，留待问题三统一引入。

\subsection{第一次检测后的联合可行集与可能位置区域}

设机器狗在第一个检测点 $S_1=(x_1,y_1)$ 测得全向干扰源的示向度为 $\theta_1$。由于有效接收半径 $a \in [1000, 1500]$ 米固定但未知，且首次获得示向度表明 $5 \le \|G - S_1\| \le a$，首次检测后的\textbf{联合可行集}为
\begin{equation}\label{eq:joint_feasible_H1}
\mathcal H_1 = \left\{ (G,a) : G \in \Omega,\ 1000 \le a \le 1500,\ 5 \le \|G - S_1\| \le a,\ d_\theta(\operatorname{arg}(G - S_1), \theta_1) \le \varepsilon \right\},
\end{equation}
其中 $\Omega = \{G \in \mathbb R^2 : \|G\| \le 1800\}$ 为目标圆域，$d_\theta$ 为模型准备中定义的角度环形距离。将 $\mathcal H_1$ 对位置 $G$ 投影，得到干扰源的\textbf{可能位置区域}为

\begin{equation}\label{eq:F1_projection}
F_1 = \left\{ G \in \Omega : 5 \le \|G - S_1\| \le 1500,\ d_\theta(\operatorname{arg}(G - S_1), \theta_1) \le \varepsilon \right\}
\end{equation}

从几何上看，$F_1$ 是以 $S_1$ 为顶点的 $2^\circ$ 示向角域、内外半径 $5$ 与 $1500$ 米的扇形环带以及目标圆域 $\Omega$ 三者的交集，边界由射线段与圆弧组成。处理物理上 direction 对应的严格下界时，这里取闭包 $5$ 米作保守计算——既不引入任意小数，也不会漏掉真实位置；等真正收到新的 direction 反馈，再明确排除相应的 $5$ 米闭圆。

\subsection{第二检测点的可靠接收区域}

第一次检测既然成功，而接收半径 $a$ 又固定未知，那么对每个可能位置 $G$ 而言，实际接收半径至少是 $a_{\min}(G) = \max\{1000,\ \|G - S_1\|\}$。于是，只要第二检测点 $X$ 落在所有这些保障性接收圆的公共部分内，机器狗就必定能收到信号。据此构建\textbf{可靠接收区域}\upcite{tokekar2013}
\begin{equation}\label{eq:C_rec}
\boxed{
C_{\mathrm{rec}} = \bigcap_{G \in F_1} B\left(G, a_{\min}(G)\right)
}\,.
\end{equation}
与忽略半径固定性的保守区域 $C_{\mathrm{rec}}^{(0)} = \bigcap_{G \in F_1} B(G, 1000)$ 相比，$C_{\mathrm{rec}}$ 用上了“同一干扰源接收半径在两次检测中保持固定”这一约束，可选的可靠检测范围因此明显扩大。

在实际数值计算中，采用覆盖 $F_1$ 的自适应外包网格单元集 $\{Q_k\}$ 进行连续可靠性认证。设单元 $Q_k$ 的中心为 $g_k$，覆盖半径为 $h_k$，则保证可靠接收的充分条件为：
\begin{equation}\label{eq:reliable_cert}
\|X - g_k\| + h_k \le \max\{1000,\ \|g_k - S_1\| - h_k\}, \quad \forall k,
\end{equation}
随边界单元自适应细化，该保守证书逐步逼近连续可靠区域，但不能把“全部样本点都满足”直接当成连续保证。

\subsection{检测点与已测区域的几何价值}

对 $X \in C_{\mathrm{rec}}$，第二次检测有两种相容反馈：返回 $\mathrm{near}$ 时 $\|G - X\| \le 5$ 米，后验可能位置区域缩小为 $F_X^{\mathrm{near}} = F_1 \cap B(X, 5)$；返回示向度 $\theta_2$ 时目标不在 $X$ 的 $5$ 米闭圆内，后验联合可行集为
\begin{equation}\label{eq:H_direction}
\mathcal H_X^{\theta_2} = \left\{ (G,a) \in \mathcal H_1 : \|G - X\| \le a,\ \|G - X\| > 5,\ d_\theta(\operatorname{arg}(G - X), \theta_2) \le \varepsilon \right\},
\end{equation}
其位置投影 $F_X^{\theta_2} = \{G : \exists a, (G,a) \in \mathcal H_X^{\theta_2}\} \subseteq F_1 \setminus B(X, 5)$。

更一般地，设已有观测形成位置集合 $F$，候选点 $X$ 处与当前假设相容的反馈集合为 $\mathcal O(X)$，反馈 $o$ 加入历史后的位置投影记为 $F^{X,o}$，则真实相容后验必满足 $F^{X,o}\subseteq F$。直觉上，与视线近共线的新点只带来高度重合的约束，交会更充分的点才会显著压缩区域；不过这一关系始终由完整后验体现，并不以两条射线的夹角来近似。

定义区域面积 $A(F)$，采用如下无量纲\textbf{几何不确定性}指标：
\begin{equation}\label{eq:phi}
\Phi(F)=\log_2\!\left(\max\left(1,\frac{r(F)}{20}\right)\right)
+\log_2\!\left(1+\frac{A(F)}{400\pi}\right),
\end{equation}
并约定 $\Phi(\varnothing)=0$。式中第一项衡量区域在最小覆盖圆尺度上与 $20$ 米清除精度的差距，第二项衡量尚未排除的位置面积，两项默认等权。需要说明的是，$\Phi$ 只是纯几何评分，既不是概率熵，也不假设干扰源在区域内均匀分布。

候选点的基础价值定义为
\begin{equation}\label{eq:delta}
\boxed{
\Delta(X\mid F)=\Phi(F)-\sup_{o \in \mathcal O(X)}\Phi(F^{X,o})
}\,.
\end{equation}
它衡量的是一次检测\textbf{在最不利相容反馈下仍能保证减少}的几何不确定性。由于面积与最小覆盖圆半径都随集合缩小而不增，恒有 $\Delta(X\mid F)\ge0$；另外，同一地点、同一频道的重复测量不会带来新的误差信息，计算时直接去重即可。

\subsection{第二检测点候选区域}

在可靠接收区域 $C_{\mathrm{rec}}$ 内，定义最优基础价值：
\begin{equation}\label{eq:delta_max}
\Delta_{\max} = \sup_{X \in C_{\mathrm{rec}}} \Delta(X\mid F_1).
\end{equation}

给定几何容差 $0 < \rho < 1$，定义第二检测点的\textbf{优良候选区域} $C_{\mathrm{good}}$：
\begin{equation}\label{eq:C_good}
\boxed{
C_{\mathrm{good}} = \left\{ X \in C_{\mathrm{rec}} : \Delta(X\mid F_1) \ge (1 - \rho)\, \Delta_{\max} \right\}
}\,.
\end{equation}
若算得 $\Delta_{\max}=0$，正确的做法是报告当前单次稳健评分无法区分各候选点，而不是声称所有点都能有效改善定位。

落实到数值认证，需对连续位置与反馈区间作保守外包，得到 $\Delta$ 的认证下界 $\Delta_L(X)$ 与上界 $\Delta_U(X)$，随后执行严格的两级筛选：凡 $\Delta_L(X) \ge (1 - \rho)\, \Delta_{\max,U}$ 者保证入选，凡 $\Delta_U(X) < (1 - \rho)\, \Delta_{\max,L}$ 者直接淘汰，其余边界待定的候选则继续细化。

这里 $\Delta_{\max,L}$、$\Delta_{\max,U}$ 分别是最优价值的认证下界与上界；为区分数值误差，误差角与各层网格都应逐项细化。还有一点值得警惕：仅取若干角度样本的最坏反馈价值通常偏小，反而会高估信息增益，因此只能用于启发式排序——候选区域由连续不等式定义，网格只是用来展示。

\subsection{第二检测点最终选择}

问题二输出连续定义的 $C_{\mathrm{good}}$ 及其中已验证的代表点。需要给出一个具体的第二检测点时，在经验证的有限代表点集 $\mathcal R_v\subseteq C_{\mathrm{good}}$ 中选取基础价值最大的点：
\begin{equation}\label{eq:S2_star}
\boxed{
S_2^* = \operatorname*{arg\,max}_{X \in \mathcal R_v} \Delta(X\mid F_1)
}\,,
\end{equation}
同分时按坐标词典序（先 $x$ 后 $y$）选取。候选集有限，破局规则又串行唯一，因此选出的 $S_2^*$ \textbf{唯一确定}，整个算法也随之完全确定。

行进距离暂不计入本问评分，从第一检测点出发的移动成本留待问题三的价值模型统一处理。至于常被提及的正交或较大交会角，它们固然可以用来生成候选，却并不是最优性的充分条件——完整的反馈几何、目标圆域及可靠接收条件仍须参与评价。

\section{问题三：动态检测与清除寻路算法}\label{sec:q3}

问题三要求对总数未知（$10\sim16$个）的全向干扰源自动搜索、定位并清除，采用\textbf{“扫描—追击”两相滚动策略}：机器狗依次访问七个扫描锚点，在每站对全部未决频道批量测量，使发现与“不存在”证明成为扫描的副产品；一有发现立即转入追击，以可能位置区域的最小覆盖圆为标尺逐次收缩并清除；已发现频道的追击目标与剩余扫描锚点合成一条开放路，每次获得反馈后重新排序。

\subsection{七点扫描基线与分区覆盖证书}

初始发现站采用原点 $Q_0=(0,0)$ 与半径 $1200$ 米正六边形的顶点
\begin{equation}\label{eq:hex_stations}
Q_k=1200\left(\cos\frac{(k-1)\pi}{3},\ \sin\frac{(k-1)\pi}{3}\right),\quad k=1,\ldots,6,
\end{equation}
七站对目标圆域的最大最近距离满足
\begin{equation}\label{eq:hex_cover}
\max_{G\in\Omega}\min_{0\le k\le6}\|G-Q_k\|\le\max\left(\frac{1200}{\sqrt3},\ \sqrt{1800^2+1200^2-4320000\cos\frac{\pi}{6}}\right)<1000,
\end{equation}
该界可按六个扇区证明（各扇区内只比较原点与外站距离，最坏值在二者等距位置或圆域边界取得），数值约 $968.9$ 米，留有约 $31$ 米裕量。因此一个全向源至少能在一站被发现；某频道七站均无信号时，可以严格排除该频道。该结论只保证发现或排除，不保证 $20$ 米精度：例如源位于 $(1800,0)$、接收半径为 $1000$ 米时，只有 $(1200,0)$ 站能收到信号，与全部反馈相容的位置构成 $1205<x\le1800$ 上的线段，区域最小覆盖圆半径至少为 $297.5$ 米，定位仍须依靠追击中的多次交会。

逐站等待“七站全无信号”进一步细化为\textbf{分区覆盖证书}：把目标圆域剖分为边长 $40$ 米的方格单元（单元外接半径 $20\sqrt2\approx28.3$ 米），构造时要求每个单元到最近锚点的最大顶点距离不超过 $999.99$ 米（连续界 $968.9$ 米加单元外接半径后恰好满足），于是\textbf{任一被无信号扫描整单元覆盖的单元，都可从该频道的可能位置中划除}。扫描时逐单元记账，全部单元被覆盖即可断定该频道不存在——这是可离线复核的严格结论；实现中另在 $100$ 米采样格上复核“任一点到最近无信号扫描站的距离不超过 $1000$ 米”，为每个被判不存在的频道写入认证字段。

单纯固定七站逐站扫描存在两类缺陷：扫描与定位割裂，先扫完全部锚点再统一追击会错过途经的清除机会；后期锚点远离残余目标，空跑路段占比上升。改进方向是发现即追击、扫描位置可在保持证书的前提下向战场迁移、并把追击与剩余扫描放进同一条路线，其收益通过同口径对照实验验证。

\subsection{可能位置区域的保守收缩与可靠清除}

对频道 $c$ 维护可能位置区域 $F_c$（凸多边形，初始为目标圆域的外接正多边形近似，保证不丢真实位置）。获得示向度 $\theta$ 后，$F_c$ 与 $\pm1^\circ$ 示向楔形（实现中按 $1.005^\circ$ 外扩）及“距检测点不超过 $1500$ 米”的圆盘外接近似求交；获得 near 时源必在 $B(X,5)$ 内，可就地清除；无信号读数不用于收缩 $F_c$，只用于更新扫描覆盖证书。由于接收半径 $a$ 未知但固定，多次正反馈的合法性由统一半径论证保障：对候选位置 $G$，令
\begin{equation}\label{eq:a_minus}
a_c^-(G)=\max\left(1000,\ \max_{X\in M_c^+}\|G-X\|\right),
\end{equation}
其中 $M_c^+$ 为有效收信点集；存在与全部记录相容的固定半径，当且仅当 $a_c^-(G)\le1500$。楔形与距离环的连续求交天然实现该检验：全部交运算都朝“不误删真实位置”的一侧放宽，任意一次收缩后 $F_c$ 仍是真实可能位置的超集。收缩后的区域既可按问题二模型计算基础价值 $\Delta_c(X)$，也可用下文的直径上界评价，二者都只作排序、不产生严格结论。

清除决策以最小覆盖圆为标尺：设 $(C_c,r_c)$ 为 $F_c$ 的最小覆盖圆，若 $r_c\le20$（实现中留 $0.01$ 米数值余量），则 $K_{20}(F_c)\ne\varnothing$，在圆心 $C_c$ 处清除必然命中。以圆心作清除点的误差可控：最小覆盖圆圆心 $C(F)$ 位于区域凸包内，任意可靠点 $X\in K_{20}(F)$ 的 $20$ 米圆覆盖该凸包，故 $\|C(F)-X\|\le20$，以可靠点换成圆心只增加至多 $4$ 秒行进。

\subsection{追击链：测量点价值与试探清除}

发现频道后进入追击链，至多 $6$ 轮，每轮依次判断：(i) 返回 near，就地清除；(ii) $r_c\le20$，按证书在圆心清除；(iii) $r_c<90$，转\textbf{试探清除}——此时区域已小，直接在圆心就地下注：成功即省去后续全部读数，失败仅耗 $3$ 秒，追击链继续收缩，不影响任何严格结论（实测失败率约 $11\%$，期望收益显著为正）；否则 (iv) 选择下一个测量点继续收缩。设当前位置为 $p$、圆心为 $C_c$，候选点 $q$ 的估计耗时为
\begin{equation}\label{eq:V_c}
\boxed{\ \hat t(q)=\frac{\|p-q\|+\|q-C_c\|+w\,D_q}{5}+6\ },
\end{equation}
其中 $D_q$ 为在 $q$ 处测量后区域直径的最坏后验上界（示向读数按 $2^\circ$ 分箱：真实示向角必落在“测量误差$+$分箱半宽”的楔形内），$w=0.25$ 为不确定项权重，$6$ 秒覆盖检测与切换开销。候选集由问题二的几何优良点与“$p\to C_c$ 线段上 $0,1/4,1/2,3/4,1$ 分点$\times$横向偏移 $0,\pm20,\pm40,\pm80,\pm140,\pm200$ 米”的走廊点组成，并施加硬性过滤：$q$ 到 $F_c$ 每点的距离不超过 $999.9$ 米——\textbf{保证下一站必然处于有效接收范围内}，杜绝在接收边界外空测。取 $\hat t$ 最小者为下一测量点，同分取更近者。式~\eqref{eq:V_c} 以“行进$+$前进$+$不确定”的统一尺度权衡交会几何与移动代价，是谨慎贪心主动定位思想\upcite{vanderhook2012,vanderhook2014}在本题多频道场景下的等价形式。

追击 $6$ 轮未成功时转入\textbf{有限后备清除}：把 $F_c$ 沿最长对角线对齐，以 $27$ 米步长的网格中心蛇形遍历——每个单元中心到单元内任一点不超过 $27\sqrt2/2\approx19.1<20$ 米，逐点清除必有一步命中。后备清除是完成性保障，与 $r_c\le20$ 的证书清除严格区分，触发次数单独记录。此外，每清除一个已发现频道后，在原地以零移动复测其余已发现频道（共享观测），同步收缩它们的区域。

\subsection{扫描位置迁移与联合开放路线}

扫描锚点并不机械照搬。每个未消费锚点负责其\textbf{临界单元}——只有它还能整单元覆盖的单元（其余未消费锚点的 $999.99$ 米圆盘都无法覆盖）；扫描位置允许从锚点沿“锚点$\to$当前位置”线段向战场内移，用二分搜索找最大内移比例，约束是其 $999.98$ 米圆盘仍完整包含临界单元集合的凸包。该迁移不损失任何覆盖证据（被移动扫描覆盖的恰是需要它覆盖的单元），却使后期扫描点显著靠近残余目标。某锚点的临界单元被清空后即退休；每个被覆盖的单元从所有频道的可能位置中划除。

已发现频道的追击顺序按\textbf{联合开放路线}确定：以各频道当前最小覆盖圆圆心为目标点，用最近邻$+$2-opt（含端点回插）求一条开放路，目标函数为路长加上末端到剩余扫描锚点的最短距离——避免追击收尾后为补齐覆盖证书而折返；每轮只执行路线首站，获得反馈后从当前位置重新排序。

\subsection{总体流程、结束条件与检验}

机器狗从原点出发，首站即扫描：对 $20$ 个频道批量测量（$20$ 次检测、$19$ 次切换，共 $119$ 秒），有信号频道立即进入追击。此后每轮：(i) 在可迁移扫描位置中选距当前位置最近者，批量测量全部未决频道；(ii) 无信号读数更新分区覆盖证书并退休已清空锚点；(iii) 有信号频道按联合开放路线逐个追击（含共享观测）；(iv) 已清除数达 $16$ 时立即收工。记录已证实存在的频道数 $E$（含已清除目标）与未判定频道数 $U$：若 $E=16$，由总数上界知其余频道必不存在，\textbf{上限短路}直接结束；否则继续扫描，直至覆盖证书耗尽，此时全部未发现频道都被严格排除。仅在成功清除 $16$ 个目标，或全部 $20$ 个频道均已清除或经覆盖证书严格排除时结束；已发现目标在未清除前出现空区域应排查数值矛盾，不作为任务完成。

策略检验通过与逐轮价值选点的 MPC 消融版本（共用协议层与记录格式）的配对对照完成，并以官方模拟器演练为准：性能结果见第~\cref{sec:q3_verify}节，实现层细节见第~\cref{sec:impl}节。

% ==================== 问题四 ====================
\section{问题四：定向约束下的检测—清除联合滚动规划}\label{sec:q4}

问题四沿用问题三的框架：可能位置的联合假设更新、计入行进距离的价值评价、以覆盖证书为判据的可靠清除与反馈后滚动重规划；新增工作集中在定向源的联合假设、无信号解释、发现保证与搜索—清除联合路线。

\subsection{定向源新增约束与影响}

一个存在假设写为 $h=(G,a,\kappa,\varphi)$，其中 $G\in\Omega$，$a\in[1000,1500]$，类型 $\kappa$ 为全向 $\mathrm O$ 或定向 $\mathrm D$；全向分支不使用朝向变量，定向单位向量为 $n(\varphi)=(\cos\varphi,\sin\varphi)$。在检测点 $X$ 的可接收指示函数为
\begin{equation}\label{eq:v_indicator}
v(X;h)=
\begin{cases}
\mathbf 1\{\|X-G\|\le a\}, & \kappa=\mathrm O,\\[2pt]
\mathbf 1\{\|X-G\|\le a,\ n(\varphi)^{\mathsf T}(X-G)\ge0\}, & \kappa=\mathrm D.
\end{cases}
\end{equation}
发射半平面含边界；示向度仍是从检测点指向源的位置方向，不是源的发射方向（几何见图~\cref{fig:q4-geom}(a)）。定向源新增的影响与调整包括：无信号解释不唯一，须保留位置、半径、类型、朝向的联合分支；AOA优良点可能无法接收，价值计算须计入相容无信号分支；朝向缩小但位置不变仍有价值，几何评分增加朝向可行范围项；圆域边界可能朝外发射，发现网格保留圆域外站点；近距离未必返回 near，清除只依赖位置覆盖证书而不等待无线电恢复。

\subsection{联合假设更新与几何价值}

记频道 $c$ 的联合假设为 $\mathcal H_c$，每频道保存全向、定向和不存在三类假设。收到 direction $\theta$ 后保留满足 $v(X;h)=1$、$\|X-G\|>5$ 且 $d_\theta(\operatorname{arg}(G-X),\theta)\le\varepsilon$ 的假设；near 保留 $v(X;h)=1$ 且距 $X$ 不超过 $5$ 米的假设；无信号保留 $v(X;h)=0$ 的假设。特别地，定向无信号要求
\begin{equation}\label{eq:d_nosignal}
\boxed{
\|X-G\|>a
\quad\text{或}\quad
n(\varphi)^{\mathsf T}(X-G)<0
}\,,
\end{equation}
须保留“或”关系，不能据此直接排除整个 $B(X,1000)$。清除失败则对所有类型统一加入 $\|X-G\|>20$，成功后删除该频道全部任务。

接收半径可对固定位置解析消去：按问题三式~\eqref{eq:a_minus} 定义
\begin{equation}\label{eq:a_minus_elim}
a_-(G)=\max\left(1000,\ \max_{X\in M^+}\|X-G\|\right),
\end{equation}
无正反馈时取 $1000$。若 $a_-(G)>1500$，该位置不可行；全向分支还要求 $a_-(G)<\min_{X\in M^0}\|X-G\|$。对定向分支，正反馈点须满足非负发射半平面约束，距 $G$ 不超过 $a_-(G)$ 的负反馈点必须满足严格背面约束，更远的负反馈可由距离解释；这些朝向开闭半圆的交集非空当且仅当存在相容的半径与朝向。该消元只用于存在性判断：新正反馈会增大 $a_-(G)$，使原本可由距离解释的旧负反馈转为必须位于背面，故评价新反馈时须重新计算并重查全部历史。

朝向信息也应纳入价值评价。记全向分支位置投影为 $F_c^{\mathrm O}$，定向分支在位置 $G$ 处的相容朝向集合为 $\Theta_c(G)$，定义无概率含义的联合几何量
\begin{equation}\label{eq:J_c}
J_c=A(F_c^{\mathrm O})+\frac{1}{2\pi}\int_{\Omega}\operatorname{len}(\Theta_c(G))\,\mathrm dG,
\end{equation}
其中朝向长度以弧度计，不存在定向假设的位置取 $0$，两项单位均为平方米。以位置总投影 $F_c$ 定义
\begin{equation}\label{eq:phi4}
\Phi_4(\mathcal H_c)=\Phi(F_c)+\log_2\!\left(1+\frac{J_c}{400\pi}\right),
\qquad
\Delta_c^{(4)}(X)=\Phi_4(\mathcal H_c)-\sup_{o\in\mathcal O_c(X)}\Phi_4\!\left(\mathcal H_c^{X,o}\right).
\end{equation}
将其替换问题二的基础价值 $\Delta$ 后，价值评价仍逐频道进行，每频道只保留一个最佳目标；该联合几何积分可近似用于评分，但不能用于未经认证的排除或清除判断。

\subsection{任意朝向的发现保证}

七点接收圆覆盖对定向源不再足够。对候选位置 $G$，若已测点中有若干点距 $G$ 不超过 $1000$ 米且 $G$ 位于这些点的凸包内，则对任意发射朝向至少有一个点位于覆盖半平面：若 $G=\sum_i\lambda_iX_i$、各权重非负且和为 $1$，则 $\sum_i\lambda_i n^{\mathsf T}(X_i-G)=0$，这些投影不可能全部严格为负，故至少一点既在发射半平面内又在必然接收距离内，即 $G\in\operatorname{conv}\{X_i:\|X_i-G\|\le1000\}$ 时 $G$ 至少被一个已测点发现。

本文用\textbf{同心环布站}实现该证书：中心 $1$ 点、内环 $6$ 点（半径 $800$ 米）、中环 $11$ 点（$1600$ 米）、外环 $12$ 点（$1900$ 米），共 $30$ 个扫描顶点（图~\cref{fig:q4-geom}(b)），全部落在真实演练已证实的 $2700$ 米停靠半径内。每个位置单元以 $24$ 个朝向区间的位图记录存活方向，站点按严格裕量计算“可证明覆盖的方向位图”并整单元删除；逐站更新后的残余方向假设为 $0$，即任意位置、任意朝向的源都会被某站发现。外环 $12$ 点是边界任意朝向覆盖的几何地板：边界点（半径 $1800$ 米）的可行覆盖顶点必落在以其径向为轴的 $\pm33.2^\circ$ 楔形内，且这些顶点的方位空隙不得超过 $180^\circ$，故外环不宜减至 $11$ 点以下。为每个未判定频道建立环形扫描必要任务，到期强制执行；自适应观测可用同样的连续凸包证据提前排除相应区域。只有当频道的全部潜在位置都已被任意方向发现证书覆盖而反馈始终无信号时，才能排除该频道。

\subsection{失联处理、清除与路线衔接}

对已发现目标，历史有效收信点的凸包是可靠接收区域的一个子集：每个固定假设的接收区域都是圆与半平面的交集，为凸集，包含全部有效收信点及其凸包。在历史收信点凸包、问题二优良交会点、换侧补测点、必要扫描顶点和途中位置中生成候选；即使可靠区域很小也允许评价外部探测点，但须计入失联反馈。失联后更新联合假设并重新选点；若位置投影的保守外包已满足最小覆盖圆半径不超过 $20$ 米，则立即生成圆心清除点，无须识别朝向或先恢复信号；迟迟无法有效定位的目标转入有限后备清除。最终检测点与清除点统一进入\textbf{联合滚动开放路线}：剩余扫描顶点、成熟频道的后备清除候选与追踪目标合并为同一条最近邻$+$2-opt 开放路，每轮反馈后从当前位置重排；定向约束只改变检测价值与候选位置，不改变边权与排序结构。

\subsection{总体流程与结束条件}

问题四同样先在原点扫描 $20$ 个频道并建立三类假设、初始化同心环布站的方向覆盖证据；已发现频道的追踪清除与全域覆盖搜索按轮\textbf{交错推进}（搜索每轮可插空、追踪不独占调度），成熟频道的后备清除候选与剩余扫描顶点合并进同一条最近邻$+$2-opt 开放路，每次反馈都重新排序。数量限制仍为 $10\sim16$，且同时存在全向与定向源，可加入“至少一个全向、至少一个定向”的全局约束；类型推断只用于收紧假设，不要求清除前先识别类型。结束条件与问题三相同；定向无信号、离散样本耗尽或连续失联均不能单独证明任务结束，发现由连续凸包证书（方向位图离散实现）保障，清除由位置覆盖证书或有限后备覆盖保障。实现层的联合单元张量、方向位图证据、同心环布站与联合路线调度等要点见第~\cref{sec:impl}节。

% ==================== 算法实现与优化设计 ====================
\section{算法实现与优化设计说明}\label{sec:impl}

前述模型与策略已全部实现为可运行的 Python 代码（\texttt{codes/} 目录）并配套单元与端到端测试；建模层创新已在问题二至四各节阐述，本节补充实现层的主要优化算法与工程设计。

\subsection{严格结论与启发式评分的分层实现}

两个问题的求解代码都遵循\textbf{“结论与评分分离”}：一切严格结论由保守判据给出，启发式只用于排序。问题三的严格层是\textbf{连续多边形保守收缩}——可能位置区域由示向楔形（按 $1.005^\circ$ 外扩）、距离上界的圆盘外接多边形近似与目标圆域外接近似连续求交，任何一次交运算都朝“不误删”一侧放宽；分区覆盖证书的覆盖界（$999.99$ 米）与扫描迁移约束（$999.98$ 米）之间留有数值裕量。问题四的严格层是“位置$\times$半径$\times$朝向”布尔张量上的必要条件过滤与方向位图判据（见下文）。启发层——问题三的最小覆盖圆目标、$2^\circ$ 分箱直径上界与测量点评分，问题四的假设抽样与追踪候选评分——只影响访问顺序与测量时机，不参与任何存在、排除或清除结论。

协议层以双时钟预算保障安全性：以单调时钟估计剩余现实时间内还能发出的动作数，容量不足时自动降级为只追已发现目标并安全收尾，不谎报完成。

\subsection{问题三：批量扫描、追击链与联合开放路线}

（1）\textbf{七锚点批量扫描}：原点与 $1200$ 米六边形环共 $7$ 个锚点承担发现与排除；每站对全部未决频道批量测量，使发现与空频道不存在证明成为扫描副产品。分区覆盖证书按 $40$ 米单元记账，空频道结论另在 $100$ 米采样格上复核覆盖半径并写入认证字段，可离线独立复核。

（2）\textbf{追击链与两级清除}：发现即追击，以最小覆盖圆收缩区域：$r_c\le19.99$ 米证书清除；$r_c<90$ 米试探清除（失败仅 $3$ 秒、不影响严格结论，实测失败率约 $11\%$）；否则按式~\eqref{eq:V_c} 选择保证收信的下一测量点。$2^\circ$ 分箱较 $4^\circ$ 在 $24$ 个同构种子上平均每例少走约 $86$ 米且审计全过。追击链平均每源仅需 $1.78$ 次测量，已接近“两条锚点示向$+$一次逼近$+$试探清除”的信息结构下限；$6$ 轮上限后由 $27$ 米步长蛇形后备清除保证完成。

（3）\textbf{扫描位置迁移与联合路线}：扫描点沿“锚点$\to$当前位置”线段二分内移，以 $999.98$ 米圆盘包含临界单元凸包为约束；已发现频道按最近邻$+$2-opt 排序并在目标函数中计入末端到剩余锚点的出口距离，清除后在原地共享观测复测其余频道，摊薄每源测量次数。

（4）\textbf{上限短路}：清满 $16$ 个源即由总数上界直接收工，避免为已确定不存在的频道补齐证书。本地官方同构 Engine $24$ 种子实测 $275.4$ 秒/源（$24/24$ 全清），较逐轮价值选点的 MPC 消融（$315.7$ 秒/源）下降 $12.8\%$。

\subsection{问题二：保守离散化与覆盖裕量认证}

问题二求解器将示向角域与候选区域边界离散化（角度步 $0.5^\circ$、径向步 $75$ 米、候选点间距 $50$ 米、边界步长 $15$ 米），示向误差只取 $\{-1^\circ,0^\circ,+1^\circ\}$ 端点枚举；可靠接收条件按离散化覆盖裕量收紧后再筛选候选点，并以 $5\%$ 的相对质量阈值生成优良候选区域，候选点质量按最坏后验定位直径的保守离散化评估。\textbf{离散化一律取保守侧}，与正文“样本点全部通过不等于连续保证”的要求一致。

问题一求解器内置正文两个算例（五检测点实例与正三角形反例）的生成、求解与校验，本文两项数值算例的全部结果均由该求解器复现。

\subsection{问题四：联合单元张量与启发式布站优化}

（1）\textbf{联合单元张量}：每频道以“位置格网（间距 $20$ 米）$\times$ 半径区间（$4$ 段）$\times$ 朝向区间（$24$ 段）”的布尔张量维护\textbf{联合假设}。反馈按区间必要条件过滤：设朝向分段数为 $A$，朝向半宽 $\pi/A$ 下单位法向点积的误差界为 $r_h+2\|G-X\|\sin\frac{\pi}{2A}$，只删除确定不可能的单元。

无信号历史在首次正观测后重放；位置维度延迟分配并及时压缩。用于评分的联合假设按上限 $64$ 抽样，只作排序、不作结论。

（2）\textbf{方向位图覆盖证据}：对未知频道的不存在判定，每个位置单元以 $32$ 位位图记录 $24$ 个朝向区间的存活方向；站点对每个单元按严格裕量计算\textbf{“可证明覆盖的方向位图”}，增益即删除的方向位总数，从而把正文的凸包发现证书实现为可增量更新的向量化判据。

（3）\textbf{同心环布站}：搜索顶点采用解析构造的同心环——中心 $1$ 点、内环 $6$ 点（$800$ 米）、中环 $11$ 点（$1600$ 米）、外环 $12$ 点（$1900$ 米），共 $30$ 点。此前的 $28$ 点模拟退火布站在“$20$ 米单元$\times24$ 朝向区间”的方向位图判据下残留 $38$ 个未排除单元——此前的 $100\%$ 清除率并未被该更严格判据证明；同心环逐站更新后的残余方向假设为 $0$，覆盖严格性与性能同时提高。外环 $12$ 点是边界任意朝向覆盖的几何地板：边界点的可行覆盖顶点必落在其 $\pm33.2^\circ$ 楔形内且方位空隙不超过 $180^\circ$，不宜减至 $11$ 点以下。全部顶点落在真实演练已证实的 $2700$ 米停靠半径内。

（4）\textbf{交错调度、联合路线与自适应追踪}：采用“搜索每轮可插空$+$追踪不独占调度”的\textbf{成对组合}——两项单独启用无效甚至更差，必须成对启停。追踪候选评分加入 $1$ 秒/米的移动代价（平均每例少走约 $97$ 米），低收益原地补测阈值上调至 $0.09$（$24/24$ 完成再降约 $1.0$ 秒/源）。把成熟频道（存活单元不超过 $24$ 个）的后备清除候选与剩余扫描顶点合并为\textbf{同一条}最近邻$+$2-opt 开放路线，后备停靠同时完成测量；对已发现目标保留有限追踪轮数上限（默认 $2$ 轮），并按存活单元数自适应缩放（$\le12$ 个单元取 $0$，$\ge25$ 个追加 $2$ 轮），达到上限即转入后备覆盖清除——追踪只压缩启发式过程，不改变清除证书与结束判据。

追踪候选由相容反馈枚举评分（只用于排序），半径接近时合并多频道信息价值且移动成本只计一次；清除点候选支持外包盒中心与迭代收缩近似最小包围圆中心，可靠清除仍由全体单元距离判据把关。

\subsection{问题二结果检验}\label{sec:q2_verify}

问题二的结果检验围绕\textbf{连续区域认证、基础价值上下界和代表点选点}三部分展开。具体地，检查 $C_{\mathrm{rec}}^{(0)}\subseteq C_{\mathrm{rec}}$ 是否成立，检查所有入选点是否满足 $\Delta_L(X)\ge(1-\rho)\Delta_{\max,U}$，所有被淘汰点是否满足 $\Delta_U(X)<(1-\rho)\Delta_{\max,L}$，并确认最终 $S_2^*$ 满足式~\eqref{eq:S2_star} 的“价值最大、同分坐标词典序”规则。具体数值随算例不同而变化，此处不列。

\subsection{问题三结果检验}\label{sec:q3_verify}

问题三的检验按\textbf{主线与消融对照}设计，报告指标包括清除比例、严格完成比例、总虚拟时间、每源平均时间、移动长度、检测与切换次数、失败清除次数及规划异常数。

主线（扫描—追击策略）在本地官方同构 Engine 的 $24$ 个种子上实现 $24/24$ 全部清除，每源平均 $275.4$ 秒；逐轮价值选点的 MPC 消融在同口径下为 $315.7$ 秒/源。2026年9月13日的官方模拟器演练主批次（$26$ 局，规模覆盖 $10\sim16$ 源）全部正确完成，$342$ 个源全部清除，各局每源均值的平均为 $269.9$ 秒（单局最好 $214.2$ 秒），平均每局动作约 $129$ 次、行进约 $13.7$ 公里，规划异常 $0$ 次；同日另两批演练（$5$ 局与 $18$ 局）分别为 $264.0$ 与 $287.1$ 秒/源，结论一致。题面要求的三次正式测试尚待进行。

\subsection{敏感性分析}\label{sec:sens}

问题三、问题四的参数敏感性在2026年9月13日的定版复核中得到三类证据。其一，\textbf{调度参数存在强交互}：问题四“搜索每轮可插空”单独启用无效果、“追踪不独占调度”单独启用使总时间上升 $11.7\%$，成对启用却下降 $3.2\%\sim4.9\%$；问题四三只规划质量旋钮在单线程确定性口径下与默认逐位相同，此前的“收益”被证实为并行基准的线程负载伪影（约 $\pm3\%$）。其二，\textbf{布站几何的可行域很窄}：问题三扫描环半径收到 $1130$ 米时分区证书越界（$995.2+28.3>999.99$ 米）不可行，$1155$ 米的 A/B 配对劣于 $1200$ 米（$+0.66\%$）；问题四同心环的环距微调与分环偏移在留出集上均无稳定改进。其三，\textbf{代价参数方向明确}：追踪候选加入 $1$ 秒/米移动代价后平均每例少走约 $97$ 米，原地补测阈值 $0.07\to0.09$ 再降约 $1.0$ 秒/源，均保持 $24/24$ 完成。可见性能对参数组合方式比对单参数取值更敏感，任何采纳都必须以同批配对或确定性口径复核。

\section{模型评价与推广}

\subsection{模型优点}

\begin{itemize}
\item \textbf{问题一：} 半平面交集刻画使定位区域成为凸多边形，顶点提取、直径计算与覆盖性判断均有明确几何基础；顶点枚举完备性与直径顶点可达性得到严格证明，并以最小覆盖圆与判据 $r(P)\leq20$ 给出可靠清除点存在性的统一检验工具。
\item \textbf{问题二：} 保留未知接收半径构造联合可行集与可靠接收区域，避免只按几何距离选点；以最坏相容反馈下几何不确定性的保证减少量为基础价值，具有纯几何可解释性。
\item \textbf{问题三：} 七点扫描与分区覆盖证书把“发现”与“不存在证明”合并为扫描副产品；批量测量与原地共享观测摊薄每源测量次数（追击平均仅 $1.78$ 次读数）；证书清除与试探清除两级配合，在保持 $100\%$ 清除率的同时逼近每次追击 $2\sim3$ 次读数的信息结构下限；清满 $16$ 个的上限短路使任务按源数自适应收尾。
\item \textbf{问题四：} 联合假设与解析消元处理位置、半径、类型与朝向的耦合，避免多维笛卡尔采样；发现保证由凸包证书给出，以方向位图离散判据与同心环 $30$ 点布站实现，外环 $12$ 点为边界朝向覆盖的几何下界；搜索顶点、追踪与后备清除合并进同一条滚动开放路线；清除只依赖位置覆盖证书，失联后仍可推进。
\item \textbf{实现层：} 严格结论与启发式评分分层实现，优化加速不牺牲正确性；解析同心环布站将排除证据的动作数压至结构下界附近；交错调度、联合路线与自适应追踪在保持完成性证书的前提下压缩总时间。
\end{itemize}

\subsection{模型不足}

\begin{itemize}
\item \textbf{问题一：} 枚举筛选复杂度约为 $O(m^3+n^2)$，检测点很多时需旋转卡壳等加速手段。
\item \textbf{问题二：} 可靠区域与最坏反馈价值的连续认证依赖自适应网格或区间计算，开销较大；误差分布未预设，结果偏保守。
\item \textbf{问题三：} 追击链的测量点评分与试探清除置信为工程拟合，依赖演练集标定；覆盖证书收尾（为空频道补齐不存在证明）在源数较少的局占比更高，小局每源时间天然偏高。
\item \textbf{问题四：} 含朝向积分的联合几何量需数值近似，只可用于评分；$30$ 点方向证书巡回是与源数无关的固定成本，源数少的局摊薄更差；追踪、步长等参数依赖演练标定，官方误差场不同时须重新校准。
\item \textbf{实现层：} 分区单元与张量分辨率及各参数依赖离线案例集标定；反馈评分与近似最小包围圆中心等启发式只用于排序，不能替代证书。
\end{itemize}
