## 1. 测试对象与数据口径

验证算法将同一干扰源的示向观测转为半平面约束，判断交集是否为空或无界，再提取有界区域顶点、计算最远顶点对及区域直径。坐标单位为米，示向度从东向逆时针计量，误差界为正负1度。

五点案例和正三角形案例均来自建模思路中的人工构造，仅用于算法验证，不是模拟器观测或正式测试成绩。计算使用未舍入角度，以下数值通常保留六位小数。

## 2. 五点定位案例

设定真实位置为 (300, 400)，计算得到非空有界凸五边形。

| 顶点 | x（米） | y（米） |
| --- | ---: | ---: |
| V1 | 300.446367 | 388.981337 |
| V2 | 312.108091 | 395.457483 |
| V3 | 314.109112 | 397.515178 |
| V4 | 295.533794 | 408.280697 |
| V5 | 291.345347 | 398.242603 |

最远端点为 V3 和 V5，区域直径为 **22.775384 米**。

半平面采用单位法向量形式 $Ap\le b$，残差定义为 $Ap-b$，正值表示违反约束。真实位置的最大残差为 -4.924922 米，说明真实位置严格位于全部角域内；所有顶点的最大残差约为 $5.68\times10^{-14}$ 米，远小于程序采用的 $10^{-7}$ 米容差。

以这对最远端点的中点为圆心、半个直径为半径时，顶点最大超出圆周 **1.259169 米**，因此这个直径圆不能覆盖该五边形。

## 3. 正三角形解析反例

三个示向角域的交集复现顶点 (0, 0)、(10, 0)、(5, 8.660254)，对应边长10米的正三角形。计算直径为 **10.000000 米**，顶点最大约束残差约为 $1.78\times10^{-15}$ 米。

取任意一条边作为圆的直径，第三个顶点到圆心的距离为 $5\sqrt{3}$ 米，而圆的半径为5米，超出 **3.660254 米**。

进一步，覆盖整个正三角形所需的最小圆半径为 $10/\sqrt{3}\approx5.773503$ 米，大于5米。因此，无论如何选择圆心，直径为10米的圆均不能覆盖该区域。这为“以定位区域直径为直径的圆不一定覆盖定位区域”提供了解析反例。
